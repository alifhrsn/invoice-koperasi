Rekening Pembayaran

Bila dikosongkan, invoice mencetak garis titik-titik untuk diisi tulis tangan. Setiap rekening yang dipakai otomatis tersimpan sebagai pilihan untuk invoice berikutnya.

Penanda Tangan

Bila diisi, nama tercetak di bawah "Hormat kami". Bila kosong, hanya garis tanda tangan. Nama yang dipakai tersimpan sebagai pilihan berikutnya.

Catatan & Cetak

Status bayar untuk pemantauan koperasi — tidak ikut tercetak di invoice.
Pengaturan di dialog cetak (penting):
• Cetak / PDF → Ukuran kertas A4, Orientasi Portrait / Tegak (muat lebih banyak item)
• Cetak Dot Matrix → Ukuran A5 (atau custom 21 × 14,8 cm), Orientasi Landscape / Mendatar
• Margins: None / Tanpa margin · Scale: 100 (jangan "Fit to page")
• Buka More settings lalu hilangkan centang "Headers and footers" agar URL, tanggal, & "Page 1 of 1" tidak ikut tercetak.
• Centang Background graphics agar garis & warna tabel ikut tercetak.
💡 Tips: Pakai tombol ⬇ Download PDF untuk hasil paling bersih — otomatis tanpa header/footer browser.

        Langkah menyiapkan Supabase (sekali saja)
        
    
          
  1. Buka supabase.com → buat akun & proyek baru (gratis).
    2. 
          
  2. Di menu SQL Editor → New query → tempel SQL di bawah → Run.
    3. 
          
  3. Di Authentication → Users, akun internal Ajeng, Nurul, May, dan Laznas dibuat oleh admin.
    4. 
          
  4. Di menu Project Settings → API: salin Project URL dan publishable key, lalu klik Hubungkan.
    5. 
          
  5. Staf masuk memakai username dan kata sandi masing-masing; data kemudian sinkron realtime.
    6. 
        

        

          Penting: SQL ini hanya mengizinkan tiga akun internal yang telah ditentukan. Pendaftaran publik harus dimatikan di pengaturan Auth.
        

        
        
        
Publishable key boleh berada di aplikasi. Akses data tetap ditolak sampai pengguna login dengan email yang ada di allowlist staf.
